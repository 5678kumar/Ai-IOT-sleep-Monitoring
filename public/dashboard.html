📋 Monitoring Information

The dashboard receives sleep monitoring data from the ESP32 through Firebase Realtime Database.


Sensor records are grouped according to the monitoring session and processed by the machine learning system.


The AI model uses heart rate, SpO₂, movement, temperature, humidity, noise index, and sleep duration to estimate the sleep quality category.


The displayed prediction is generated by the trained Random Forest machine learning model.
